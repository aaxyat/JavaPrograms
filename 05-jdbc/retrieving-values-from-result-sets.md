# Unit 5: JDBC

## Retrieving Values from Result Sets

A **JDBC Result Set** (`java.sql.ResultSet`) maintains a cursor pointing to a table of data generated by executing a SQL `SELECT` query. Applications navigate through this row grid using cursor methods and extract column values using type-specific getter methods.

---

### Core Concepts

#### 1. ResultSet Types and Concurrency Modes
When creating a `Statement`, you can configure how the `ResultSet` cursor navigates through rows:

```java
Statement stmt = conn.createStatement(
    ResultSet.TYPE_SCROLL_INSENSITIVE, // Scrollable backwards/forwards
    ResultSet.CONCUR_READ_ONLY         // Read-only concurrency mode
);
```

| Result Set Type | Navigation Capabilities | Description |
|-----------------|-------------------------|-------------|
| **`TYPE_FORWARD_ONLY`** | Forward only (`next()`). | **Default & Highest Performance.** Moves sequentially from top to bottom. |
| **`TYPE_SCROLL_INSENSITIVE`** | Scrollable in any direction. | Cursor moves forward (`next()`), backward (`previous()`), to absolute rows (`absolute(n)`), or relative rows (`relative(n)`). Insensitive to concurrent database changes. |
| **`TYPE_SCROLL_SENSITIVE`** | Scrollable in any direction. | Reflects live database record updates made by other concurrent transactions while open. |

#### 2. Getter Methods by Data Type

| SQL Data Type | Java Type | Preferred Getter Method |
|---------------|-----------|-------------------------|
| `VARCHAR` / `TEXT` | `String` | `getString(columnName)` / `getString(columnIndex)` |
| `INTEGER` / `INT` | `int` | `getInt(columnName)` |
| `BIGINT` | `long` | `getLong(columnName)` |
| `DECIMAL` / `DOUBLE` | `double` | `getDouble(columnName)` |
| `BOOLEAN` / `BIT` | `boolean` | `getBoolean(columnName)` |
| `DATE` | `java.sql.Date` / `LocalDate` | `getDate(columnName)` / `getObject(columnName, LocalDate.class)` |
| `TIMESTAMP` | `java.sql.Timestamp` | `getTimestamp(columnName)` |

#### 3. Handling SQL `NULL` Values (`wasNull()`)
Java primitive types (`int`, `double`, `boolean`) cannot be `null`. When `rs.getInt()` or `rs.getDouble()` encounters an SQL `NULL` database cell, the method returns `0` or `0.0`. To distinguish between an actual database `0` and an SQL `NULL`, invoke `rs.wasNull()` immediately after the getter call:

```java
int bonus = rs.getInt("bonus");
if (rs.wasNull()) {
    System.out.println("Bonus is SQL NULL");
} else {
    System.out.println("Bonus value: " + bonus);
}
```

#### 4. ResultSet Metadata (`ResultSetMetaData`)
`rs.getMetaData()` returns a `ResultSetMetaData` object that describes column structures dynamically without prior knowledge of the SQL query schema:
- `getColumnCount()`: Returns total number of columns.
- `getColumnName(index)` / `getColumnLabel(index)`: Returns column header string.
- `getColumnTypeName(index)`: Returns SQL data type name (e.g. `VARCHAR`, `INTEGER`).

---

### Common Pitfalls

1. **Confusing SQL `NULL` with `0`**:
   - Calling `rs.getInt("discount")` returns `0` for SQL `NULL`. Relying solely on `rs.getInt() == 0` causes logic bugs if `0` is a valid discount value. Always verify with `rs.wasNull()`.
2. **Calling Scrollable Methods on `TYPE_FORWARD_ONLY` ResultSets**:
   - Invoking `rs.previous()` or `rs.first()` on default forward-only result sets throws a `SQLException: Invalid operation for forward only resultset`.
3. **Using 1-Based Column Indexing Improperly**:
   - JDBC column indices start at `1` (`rs.getString(1)`), not `0`. Passing `0` throws an `ArrayIndexOutOfBoundsException` or `SQLException`.

## 1. Demo: Forward & Scrollable ResultSets with SQL NULL Checking

### `ResultSetRetrievalDemo.java`

```java
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.Statement;
import java.sql.ResultSet;
import java.sql.SQLException;

/**
 * Demonstrates forward and scrollable ResultSet navigation, type-specific getters, and checking SQL NULL values with wasNull().
 */
public class ResultSetRetrievalDemo {

    private static final String DB_URL = "jdbc:h2:mem:rs_demo_db;DB_CLOSE_DELAY=-1";

    public static void main(String[] args) {
        
        try (Connection conn = DriverManager.getConnection(DB_URL, "sa", "");
             Statement stmt = conn.createStatement(ResultSet.TYPE_SCROLL_INSENSITIVE, ResultSet.CONCUR_READ_ONLY)) {

            // 1. Setup Table and Seed Data (including NULL values)
            stmt.execute("CREATE TABLE products (id INT PRIMARY KEY, name VARCHAR(50), price DOUBLE, bonus_discount INT)");
            stmt.executeUpdate("INSERT INTO products VALUES (101, 'Pro Laptop', 1299.99, 150)");
            stmt.executeUpdate("INSERT INTO products VALUES (102, 'Wireless Earbuds', 79.50, NULL)"); // Contains SQL NULL
            stmt.executeUpdate("INSERT INTO products VALUES (103, 'Desktop Monitor', 249.00, 0)");  // Contains Actual 0

            // 2. Query Data and Process SQL NULL Values
            System.out.println("=== 1. FORWARD ITERATION & WASNULL() CHECKING ===");
            try (ResultSet rs = stmt.executeQuery("SELECT id, name, price, bonus_discount FROM products")) {
                while (rs.next()) {
                    int id = rs.getInt("id");
                    String name = rs.getString("name");
                    double price = rs.getDouble("price");
                    
                    int discount = rs.getInt("bonus_discount");
                    String discountStr;
                    if (rs.wasNull()) {
                        discountStr = "SQL NULL (No Discount Configured)";
                    } else {
                        discountStr = "$" + discount;
                    }

                    System.out.printf("Item #%d | Name: %-18s | Price: $%7.2f | Discount: %s%n",
                            id, name, price, discountStr);
                }

                // 3. Demonstrate Scrollable ResultSet Capabilities
                System.out.println("\n=== 2. SCROLLABLE RESULTSET NAVIGATION ===");
                
                // Move to Last Row
                if (rs.last()) {
                    System.out.println("Last Row -> ID: " + rs.getInt("id") + " | Name: " + rs.getString("name"));
                }

                // Move to First Row
                if (rs.first()) {
                    System.out.println("First Row -> ID: " + rs.getInt("id") + " | Name: " + rs.getString("name"));
                }

                // Move to Absolute Row #2
                if (rs.absolute(2)) {
                    System.out.println("Absolute Row #2 -> ID: " + rs.getInt("id") + " | Name: " + rs.getString("name"));
                }
            }

        } catch (SQLException e) {
            System.err.println("ResultSet Retrieval Exception: " + e.getMessage());
        }
    }
}
```

### Explanation

1. **Scrollable Statement Configuration**:
   - `ResultSet.TYPE_SCROLL_INSENSITIVE` enables calling `rs.last()`, `rs.first()`, and `rs.absolute(2)`.

2. **Handling SQL `NULL` with `wasNull()`**:
   - `rs.wasNull()` distinguishes between row #102 (`bonus_discount` is `NULL`) and row #103 (`bonus_discount` is numeric `0`).

## 2. Practical Program: Dynamic SQL Result Set Exporter & Table Formatter

### `DynamicDataGridExporter.java`

```java
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.Statement;
import java.sql.ResultSet;
import java.sql.ResultSetMetaData;
import java.sql.SQLException;

/**
 * Generic SQL Query Exporter using ResultSetMetaData to extract column headers and data types dynamically.
 */
public class DynamicDataGridExporter {

    private static final String DB_URL = "jdbc:h2:mem:exporter_db;DB_CLOSE_DELAY=-1";

    public static void exportQueryResultToConsole(Connection conn, String sqlQuery) throws SQLException {
        System.out.println("=========================================================================");
        System.out.println("EXECUTING DYNAMIC QUERY: " + sqlQuery);
        System.out.println("=========================================================================");

        try (Statement stmt = conn.createStatement();
             ResultSet rs = stmt.executeQuery(sqlQuery)) {

            // Extract Result Set Metadata
            ResultSetMetaData metaData = rs.getMetaData();
            int columnCount = metaData.getColumnCount();

            // Print Header Row
            for (int i = 1; i <= columnCount; i++) {
                String colLabel = metaData.getColumnLabel(i);
                String typeName = metaData.getColumnTypeName(i);
                System.out.printf("%-20s", colLabel + " (" + typeName + ")");
            }
            System.out.println();
            System.out.println("-------------------------------------------------------------------------");

            // Print Row Records Dynamically
            int rowCount = 0;
            while (rs.next()) {
                rowCount++;
                for (int i = 1; i <= columnCount; i++) {
                    Object val = rs.getObject(i);
                    String cellText = (val == null) ? "NULL" : val.toString();
                    System.out.printf("%-20s", cellText);
                }
                System.out.println();
            }

            System.out.println("-------------------------------------------------------------------------");
            System.out.println("Total Rows Returned: " + rowCount);
            System.out.println("=========================================================================\n");
        }
    }

    public static void main(String[] args) {
        try (Connection conn = DriverManager.getConnection(DB_URL, "sa", "");
             Statement stmt = conn.createStatement()) {

            // Create sample schema and data
            stmt.execute("CREATE TABLE orders (order_id INT, customer VARCHAR(40), amount DOUBLE, is_paid BOOLEAN)");
            stmt.executeUpdate("INSERT INTO orders VALUES (5001, 'Acme Corp', 1450.75, true)");
            stmt.executeUpdate("INSERT INTO orders VALUES (5002, 'Beta Ltd', 890.00, false)");
            stmt.executeUpdate("INSERT INTO orders VALUES (5003, 'Gamma Inc', NULL, true)");

            // Export query results dynamically
            exportQueryResultToConsole(conn, "SELECT order_id, customer, amount, is_paid FROM orders");

        } catch (SQLException e) {
            System.err.println("Export Failure: " + e.getMessage());
        }
    }
}
```

### Explanation

1. **Dynamic Metadata Extraction (`ResultSetMetaData`)**:
   - `metaData.getColumnCount()`, `metaData.getColumnLabel()`, and `metaData.getColumnTypeName()` extract table layout attributes dynamically without prior knowledge of column names.

2. **Generic Value Retrieval (`rs.getObject(i)`)**:
   - `rs.getObject(i)` retrieves any column data type as a generic `Object`, formatting `null` database values cleanly as `"NULL"`.
